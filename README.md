# Data Professional Survey Breakdown Dashboard (Power BI)

An interactive Power BI dashboard analyzing career trends, compensation, programming language preferences, and work-life satisfaction across **504 global data professionals**.

---

## Project Workflow & Technical Highlights
* **Data Cleaning & Transformation (Power Query):** Cleaned raw survey responses directly inside Power BI's **Power Query Editor**—splitting multi-select job titles and programming languages into clean primary categories, converting salary range strings into numeric midpoints (`Average Salary`), standardizing country names, and handling missing entries.
* **Interactive Data Visualization:** Designed a single-page executive layout combining KPI cards, Gauge visuals (`1–10` satisfaction scales), a Treemap, Donut chart, and stacked bar/column charts with cross-filtering.

---

## Key Insights & Findings
* **Compensation by Role:** **Data Scientists** command the highest average salary (`~$94K`), followed by **Data Engineers** (`~$65K`) and **Data Analysts** (`~$55K`).
* **Dominant Tech Stack:** **Python** is overwhelmingly the #1 favorite programming language across every data role, far ahead of **R** and **C/C++**.
* **Geographic Distribution:** Survey respondents are concentrated in the **United States**, followed by **India**, the **United Kingdom**, and **Canada**.
* **Barrier to Entry & Satisfaction:** Over **41.87%** of respondents rated breaking into data as *Difficult* (plus `7.74%` *Very Difficult*). While **Work/Life Balance** scores a moderate **`5.72 / 10`**, **Happiness with Current Salary** averages **`4.26 / 10`**, highlighting strong upward mobility motivation among analysts.
